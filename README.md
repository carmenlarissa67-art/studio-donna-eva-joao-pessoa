# Studio Donna Eva · João Pessoa

Site com agendamento online do Studio Donna Eva (Mumbaba, João Pessoa - PB), com 3 profissionais: unhas, cílios e sobrancelhas.

- Todos os dados ficam em `src/data/studioData.js`: profissionais, serviços e valores de cada uma, combo, horários, WhatsApp e Calendly.
- O agendamento começa pela escolha da profissional, e a mensagem do WhatsApp já sai com o nome dela.

```bash
npm install
npm run dev     # desenvolvimento
npm run build   # build de produção (Vercel usa este comando)
```

## Pendências antes da entrega

- Nome da nail designer (no site aparece como "Donna Eva Nails").
- Valores reais das três profissionais (hoje são estimativa, menos o Combo Black Beauty de R$ 190).
- Horário de funcionamento (estimado: seg a sex 08h às 18h, sáb 08h às 14h).
- Calendly do Studio (hoje usa a agenda de teste).
